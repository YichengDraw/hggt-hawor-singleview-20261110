能量占比描述误差的方向，不是准确率。总体值将所有关节平方误差汇总后计算，较大的误差贡献更多；并非四条序列百分比的简单平均。RMSE 也不同于上方的 MPJPE。

计算方法、适配结果与适用范围

每个有效手帧，取从相机原点指向 GT 手腕的单位向量 u。每关节误差 e = 预测 − GT，视线分量为 e·u，横向平方误差为 ||e||² − (e·u)²。视线能量占比 = Σ(e·u)² / Σ||e||²；视线 RMSE = √mean((e·u)²)，横向 RMSE = √mean(||e||² − (e·u)²)。手偏离画面中心时，视线不等于相机 Z 轴。

三种几何统一使用 GT、HGGT 原生、HGGT 适配后和 HaWoR 的共同有效手帧与关节；共 715 手帧、15,015 关节，来源是网站公开的相机空间关节 JSON。无逐帧 GT 对齐、去腕或 PA 对齐。GT 只用于评分及定义视线。JSON 坐标精度为微米级，统计值按显示精度舍入。

结果针对四个开发样例，不是论文全基准结论。绝对位置分解同时包含整体平移和局部关节误差；如需判断手指局部形状，应结合去腕指标。此分析没有通过新的训练或推理挑选样例。
